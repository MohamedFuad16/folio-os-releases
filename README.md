# Folio OS releases

Folio OS is a Mac app that runs coding agents from several providers in one place: Claude Code, Codex and Cursor.

This repository holds release files only. The source code is private.

## Install

1. Download the `.dmg` from the [latest release](https://github.com/MohamedFuad16/folio-os-releases/releases/latest). It runs on Apple silicon Macs.
2. Open it and drag Folio OS (Beta) to Applications.
3. The app is self-signed and not notarized. The first time, Control-click Folio OS (Beta) in Applications and choose Open.

## Updates

Folio OS 0.0.55 and later check this repository for new versions. A new version shows up inside the app: download it, then restart.

To turn update checks off, set `FOLIO_OS_DISABLE_AUTO_UPDATE=true`.
